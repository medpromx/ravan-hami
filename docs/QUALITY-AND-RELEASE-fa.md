# کنترل کیفیت، انتشار و سیاست گیت علمی

## وضعیت نسخه مرجع روان‌حامی

گزارش مرحله سوم می‌گوید ۱۹۰ ورودی در inventory تطبیق هش شدند، ۴۰ پیش‌نویس Markdown و HTML آماده‌اند، و تطبیق ساختاری ۴۰/۴۰ PASS بوده؛ اما بازبینی علمی/حقوقی و مرور تصویری کامل انجام نشده و **صفر درسنامه برای نشر عمومی تأیید شده**. این داده‌ها گزارش پروژه قبلی هستند، نه نتیجه ممیزی علمی این بسته.

## Release Gate

| Gate | بررسی لازم | مسئول پیشنهادی |
|---|---|---|
| G0 Intake | شناسه، دامنه فصل، قرارداد فایل و منشأ | مدیر محتوا |
| G1 Citation | نسخه اصلی، locator، اعداد/ملاک‌ها، موارد تعارض | پژوهشگر منبع |
| G2 Scientific | DSM-5-TR و دستورالعمل‌های بالینی بر حسب حوزه؛ پاسخ‌های سؤال | متخصص روان‌شناسی/مشاوره |
| G3 Legal | اخلاق/قوانین/رضایت/حریم خصوصی، نسخه معتبر | متخصص حقوق/اخلاق در صورت نیاز |
| G4 Editorial | فارسی، لحن، جدول، تناسب با فصل و عدم حشو | ویراستار |
| G5 Technical | اسکیما، UID، لینک، RTL، صفحه‌کلید، حالت تاریک/روشن/چاپ | توسعه‌دهنده QA |
| G6 Release | تأیید صریح، گزارش تغییر، وضعیت `PUBLISHED` | مسئول انتشار |

هیچ وضعیت `DRAFT_REVIEW_REQUIRED` یا `DEMO_ONLY` نباید در خروجی release به عنوان درسنامه تاییدشده باشد. تنها build شدن HTML یا PASS شدن تست ساختاری **تأیید علمی محسوب نمی‌شود**.

## چک‌لیست تحریری و کلینیکی

- [ ] تعریف و طبقه‌بندی درست در ابتدای واحد مرتبط.
- [ ] هر ملاک/عدد/مدت/استثنا و نسخه DSM یا قانون با locator واقعی تأیید شده.
- [ ] منابع قدیم و جدید در صورت تعارض صریحاً مقایسه شده.
- [ ] مفاهیم افتراق، سیر و درمان مبتنی بر شواهد مطابق دامنه فصل هستند.
- [ ] فصل ۰۱ فقط آسیب‌شناسی و عوامل خطر را دارد؛ ارزیابی و مدیریت بحران در فصل ۰۳ است.
- [ ] متن‌های اورژانس/خودکشی دارای محدودیت آموزشی و ضوابط ایمنی هستند.
- [ ] شواهد بررسی‌نشده با ادعای قطعی یا نام رسمی آزمون منتشر نمی‌شوند.

## چک‌لیست آزمون و داده

- [ ] شناسه‌های یکتا و ثابت، `revision` معتبر.
- [ ] چهار گزینه، یک کلید صفرمبنا، چهار تحلیل **اختصاصی**، نکته طلایی.
- [ ] سال و منشأ سؤال گذشته مستند و حق بازنشر مشخص.
- [ ] عدم ابهام دوپاسخی/سرنخ کلید/تکرار معنایی.
- [ ] شمار فایل‌های فصل ۰۱ تاریخی ۱۳+۳+۱+۱ و ۹۶ سؤال پس از ورود واقعی داده‌ها تطبیق می‌شود.
- [ ] پرسش‌های فاقد منبع یا پاسخ بازبینی‌شده `NOT_RELEASED` می‌مانند.

## دستورات بررسی

```bash
python3 scripts/build.py
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
python3 scripts/build.py --release
python3 scripts/validate.py --release
python3 scripts/build.py  # return to clearly labeled technical preview
```

`--release` در این مرحله **صفر سؤال واقعی** منتشر می‌کند. این رفتار محافظه‌کارانه، عمدی است؛ بعد از ایجاد بانک واقعی و پایپ‌لاین تأیید، شرط‌های publisher گسترش می‌یابند. قبل از commit محیط release، build پیش‌نمایش را با release جایگزین کنید و هرگز خروجی demo را به عنوان آموزش تاییدشده معرفی نکنید.
