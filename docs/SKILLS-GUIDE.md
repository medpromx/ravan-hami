# Project Skills — English, Repository-local (v0.2.0)

Canonical files: `.agents/skills/*/SKILL.md`. Mirrors (generated by `scripts/sync-skills.py`, checked by tests): `.claude/skills/` and the plugin package `plugins/ravan-hami/skills/`.

| Skill | Invoke for | Primary output |
|---|---|---|
| `rh-project-orchestrator` | Any major multi-step Ravan-Hami feature | Scope map + dispatch + acceptance checklist |
| `rh-source-ingest` | New raw archives, inventory, per-subchapter working packets | `sources/inventory.json`, `work/RH-XX-YY/` |
| `rh-subchapter-pipeline` | Turning phase drafts into one canonical subchapter | Lesson MD + question JSON + ledgers + QA report |
| `rh-editorial-style` | Persian register, headings, orthography, MCQ Markdown | Edited Markdown + lint pass |
| `rh-lesson-authoring` | Learning-unit frames and front matter | Markdown with source audit status |
| `rh-question-bank` | MCQs, answer analyses, import/revision | JSON and QA record |
| `rh-source-audit` | Claims, laws, DSM references, conflicts | Provenance/claim ledger |
| `rh-legacy-migration` | Chapter 01 units, legacy HTML banks | Literal imports + migration map |
| `rh-site-architecture` | Repository hierarchy, deployment or API decisions | ADR + route/data architecture |
| `rh-rtl-design-system` | Fonts, palettes, cards, navigation and accessibility | Tokens + tested CSS/HTML patterns |
| `rh-static-builder` | Pages, menus, rendering and GitHub Pages | Generated HTML + navigation tests |
| `rh-release-qa` | Publication, testing and security | Pass/fail report + release gate |

## Recommended chain for a subchapter
`rh-source-ingest` → `rh-subchapter-pipeline` (uses `rh-editorial-style`, `rh-lesson-authoring`, `rh-question-bank`, `rh-source-audit`) → `rh-static-builder` → `rh-release-qa`. Legacy material enters through `rh-legacy-migration`.

## Plugin
`.claude-plugin/marketplace.json` exposes `plugins/ravan-hami` (12 skills, 5 commands, 2 read-only agents). Once the repository is on GitHub: `/plugin marketplace add <owner>/<repo>` then `/plugin install ravan-hami@ravan-hami`. Inside this repository the same skills load automatically from `.claude/skills/`.

Edit canonical source only, preserve stable UIDs, keep unresolved medical/legal content `DRAFT_REVIEW_REQUIRED`, and never bypass the release gate.
