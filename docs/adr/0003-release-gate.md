# ADR-0003: Scientific/legal gate precedes publishing
**Status:** Accepted — 2026-10-22

**Context:** Prior status report records 0 approved chapters, while structural conversions passed. **Decision:** Draft/demo content is not eligible for public instructional release. Only explicitly reviewed `PUBLISHED` assets can enter a release build. **Tradeoff:** Slower initial content output; prevents treating generated unverified educational material as authoritative. **Future:** Admin multi-stage reviewer signatures and source assertions.
