## منابع صرفاً اشاره‌شده، نه ممیزی کامل

کتاب‌های DSM-5-TR و سایر رفرنس‌های چاپی، متن کامل همه ۱۸ HTML مرجع فصل اول، پوشه‌های بزرگ Google Drive، نوت‌بوک‌های منبع/سؤال، ۱۹۰ فایل اولیه report، منبع رسمی آزمون جاری، خود فایل‌های علمی پشت ادعاها و تمام محتویات دو آرشیو Skill **ممیزی علمیِ خط‌به‌خط نشده‌اند**. طراحی فنی و اسکیماهای این بسته نمی‌تواند جایگزین تطبیق مستقیم منابع اصلی شود.

## Reference Registry (schema آینده)

| فیلد | توضیح |
|---|---|
| `ref_id` | شناسه پایدار کتاب/آیین‌نامه/مقاله/دفترچه |
| `title`, `edition`, `publication_year` | فقط داده احراز شده |
| `origin_uri` | DOI/URL/شناسه فایل معتبر در صورت وجود |
| `locator` | صفحه/فصل/بند دقیق، اگر در دسترس |
| `checked_scope` | صفحات و بخش‌های واقعاً دیده‌شده |
| `verification_status` | `LISTED`, `RETRIEVED`, `CHECKED`, `CONFLICT`, `SUPERSEDED` |
| `checked_by`, `checked_at` | ثبت مسئول و زمان |
| `reuse_rights` | مجوز/وضعیت حق نشر و حدود نقل |

تفاوت `LISTED` / `RETRIEVED` / `CHECKED` باید در UI ادمین و گزارش QA محفوظ بماند. متن تألیفی از رفرنس باید بازنویسی مستقل باشد؛ رونویسی کتاب یا بانک سؤال دارای محدودیت حق نشر مجاز نیست.
