## Backlog منتخب

**P0:** پایه سایت، schema و validator، سؤالات با چهار دلیل، بررسی لینک، گزارش ادعاهای معلق، سایت قابل خواندن بدون اتصال به API.  
**P1:** شباهت معنایی سؤال، Question Map، flashcards، جست‌وجوی کامل، سنجش پوشش هر رفرنس، خروجی HTML مستقل، موتور سازگاری فصل ۰۱.  
**P2:** هویت/پرداخت/یادداشت شخصی/آزمون سفارشی/مرور فاصله‌دار/مشاوره، با پایگاه داده واقعی و مجوز دسترسی قابل لغو.  
**P3:** انجمن، رتبه‌بندی اختیاری، آزمون‌های جامع، گزارش‌های گروهی محافظت‌شده و مسیر روان‌پزشکی.

## ریسک‌ها و کنترل

- ریسک ادعای علمی نامعتبر → انتشار با `PUBLISHED` و ثبت reviewer/locator فقط.
- ریسک کپی غیرمجاز → اجازه استفاده/بازنویسی علمی و سوابق منشأ.
- ریسک منسوخ شدن مقررات → فیلد effective_date و بازبینی تقویمی.
- ریسک چندگانگی بین دو آزمون → canonical unit و overlays رشته‌ای.
- ریسک feature creep → Static MVP قبل از backend؛ ADR رسمی برای مهاجرت.
- ریسک حریم خصوصی → هیچ اطلاعات داوطلب/مراجع در repository عمومی.
