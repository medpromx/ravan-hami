# راهنمای نگارش محتوا و Design System روان‌حامی

## ۱. فلسفه Learning Unit

هر واحد یادگیری هدف ذهنی/تشخیصی/حرفه‌ای مشخص داشته باشد. دانه‌بندی مطلوب: نه «فقط یک کلمه/دارو»، نه «کل فصل در یک صفحه». معماری از مدل پزشکی الهام می‌گیرد، ولی واحدهای بالینی/اخلاقی روان‌شناسی به تشخیص، مداخله، افتراق، قوانین و تصمیم حرفه‌ای تبدیل می‌شوند.

**سلسله‌مراتب محتوا:** `Exam → Domain/Course → Chapter → Subchapter → Learning Unit → Frame → Content Block → Fact → Question Cluster → MCQ`. منبع در یک `Fact/Assertion` یا بلوک قابل ارجاع است؛ سؤال می‌تواند به چند واحد پیوند بخورد.

## ۲. الگوی استاندارد درسنامه

برای فصل ۰۱ و سایر مباحث تشخیصی ترتیب: تعریف/جایگاه → ملاک دقیقِ بازنویسی‌شده از DSM-5-TR → تظاهرات → شیوع/عوامل خطر مستند → سبب‌شناسی → افتراق → سیر/پیش‌آگهی → مرور درمان مبتنی بر شواهد → جدول طلایی، فلش‌کارت و سؤال. برای اخلاق، بحران، مشاوره و سنجش بخش‌ها با ماهیت موضوع سازگار شود؛ مثلاً **ملاک DSM** را در فصل اخلاق به‌زور وارد نکنید.

### Frameها (نوع و نقش)

| Component / Frame | استفاده در روان‌حامی | ساختار |
|---|---|---|
| `OfficialCompactFrame` | متن فشرده و رفرنس‌محور | تعریف، معیار، جدول، استثنا |
| `TeacherNarrative` | توضیح چرایی به زبان روشن | از کل به جزء، مثال، نتیجه |
| `MentalAlgorithm` | مسیر تصمیم حرفه‌ای/تحلیل کیس | داده → افتراق → اقدام امن یا پاسخ |
| `QuestionMap` | خوشه‌های الگوی طراح | سؤال قدیمی مستند + الگو + دام احتمالی |
| `DifferentialArena` | مقایسه اختلال‌ها/موقعیت‌ها | جدول ویژگی ممیز، زمان، استثنا |
| `EthicsAndScopeBox` | اخلاق، رضایت، حدود صلاحیت | متن مرجع قانونی و تاریخ اعتبار |
| `CrisisSafetyBox` | اصول آموزشی خطر و ارجاع | هشدار آموزشی، بدون جایگزینی تصمیم بالینی |

| `ExamTrapBox` | خطاهای رایج | فرض نادرست، صورت درست، استناد |
| `MCQCard`/`OptionAnalysis` | آزمون و مرور | چهار گزینه، یک کلید، چهار توضیح |

### قواعد نوشتار

- فارسی معیار، نیم‌فاصله صحیح، پرهیز از حشو و نتیجه‌گیری بی‌دلیل؛ واژه انگلیسی علمی در `bdi dir="ltr"` یا span جداگانه.
- سطح ۱: فهم پایه؛ سطح ۲: استدلال آزمونی؛ سطح ۳: افتراق پیشرفته/تعارض منبع. سه سطح **زاویه ارائه** هستند نه سه حقیقت متفاوت.
- عدد تشخیصی، زمان، آستانه، شیوع، منع مصرف، دوز و قوانین به source locator قابل بررسی نیاز دارند. هرگز صفحه/سال/منبع جعلی نساز.
- محتوای قانون و حدود صلاحیت به تاریخ اجرا و مرجع حقوقی وابسته است؛ تغییرات و اختلاف با نسخه قبل برچسب بخورد.
- داده آموزشی درباره خودکشی/بحران جایگزین راهنمای حرفه‌ای فردی و مداخله فوری نیست؛ تعامل آموزشی با تریاژ واقعی مخلوط نشود.
- ۹۶ سؤال فقط مرجع بانک فصل ۰۱ است؛ برای سایر فصل‌ها تعداد را از پوشش و نیاز استخراج کن.

## ۳. ساختار استاندارد صفحه‌ها

**Home:** برند → انتخاب آزمون فعال → مسیرهای آینده → راهنمای مطالعه/وضعیت منابع.  
**Exam Portal:** نوار بالای ثابت → breadcrumb → توضیح مسیر → کارت ۱۰ فصل → فیلتر/جست‌وجو در نسخه بعد.  
**Chapter:** عنوان + زیرفصل‌ها + فهرست درسنامه‌های جدا + بانک تست همان فصل.  
**Lesson:** breadcrumb → عنوان و وضعیت علمی → ابزار تم/قلم → فهرست سمت راست → Frameها → فلش‌کارت → CTA سؤال مرتبط → منابع.  
**Question Bank:** فیلتر، جست‌وجو، وضعیت پاسخ → سؤال و چهار رادیو → ثبت → پاسخ کوتاه → استدلال مدرس → تحلیل چهار گزینه → نکته طلایی → لینک درسنامه.  
**Future Dashboard:** آمار مطالعه واقعی، مرور بعدی، تغییر برنامه با رضایت کاربر و منبع رویداد.

## ۴. Tokens و UI

| Token | Light | نقش |
|---|---|---|
| `--brand` | `#0f6b66` | هویت فیروزه‌ای روان‌حامی |
| `--navy` | `#243d56` | ساختار رسمی و عنوان |
| `--bg` | `#f6f5f0` | زمینه کاغذی |
| `--panel` | `#fffefa` | کارت مطالعه |
| `--gold` | `#916315` | نکته طلایی |
| `--danger` | `#a83535` | دام/هشدار و خطا |
| `--safe` | `#1d6e48` | ایمنی و اقدام صحیح |
| `--info` | `#315b88` | تعریف و توضیح |

Dark theme از متغیرهای معادل CSS ساخته شده است؛ **کنتراست واقعی** باید در مرورگر ممیزی شود. رنگ به تنهایی نشانه درست/غلط یا ایمنی نباشد؛ متن و نماد نیز نمایش داده شود.

- `font-family`: `Vazirmatn`, fallback `Segoe UI`, `Tahoma`, sans-serif. هیچ فایل فونتی در بسته توزیع نشده است؛ CDN صرفاً اختیاری است.
- متن درسنامه `17px` با کنترل `14–22px` و line-height حدود `2.05`؛ بدنه مطالعه ۹۰۰px و پوسته ناوبری ۱۱۲۰px.
- `lang=fa`, `dir=rtl`, چیدمان CSS logical properties (`padding-inline`, `border-inline-start`, `text-align:start`).
- جدول در والد `.table-scroll` با پیمایش افقی موبایل؛ چاپ سفید/سیاه و حذف عناصر کنترلی.
- `aria-label`, `role=radiogroup`, focus visible، دکمه‌های واقعی به جای المان کلیک مصنوعی.
- کلاس‌های مرجع برای انطباق با فصل ۰۱: `.box.def`, `.box.gold`, `.box.trap`, `.box.clin`, `.box.safe`, `.box.num`.
- تنظیمات محلی namespaced `rh:v1:settings:*`، پاسخ‌ها با مسیر/فصل/uid/revision. شکست localStorage نباید مشاهده محتوا را متوقف کند.

## ۶. اصل عدم تعارض

محتوای تاییدشده باید از منبع canonical ساخته شود. «درسنامه تفکیکی»، «زیرفصل جامع»، «بانک سؤال» و «پورتال جامع» اگر هرکدام به صورت دستی همزمان ویرایش شوند، جواب‌ها واگرا می‌شود؛ بنابراین renderer واحد و تست تطبیق محتوا الزامی است. فایل‌های قدیمی ابتدا به صورت `legacy/` وارد، با SHA ثبت، و فقط با mapping واضح migrate شوند.
